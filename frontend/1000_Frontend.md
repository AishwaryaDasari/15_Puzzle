# Frontend Design: Retro Video Game Aesthetic

This document outlines the visual design for the 15-puzzle game, aiming for a retro video game look and feel, reminiscent of 8-bit and 16-bit era games.

## Color Palette

*   **Background**: A dark color, like a deep blue or charcoal grey (`#202040`).
*   **Text**: A bright, contrasting color, like a neon green (`#39FF14`) or a classic video game yellow (`#FFFF00`).
*   **Tiles**: A solid, bright color for the tiles, such as a medium blue (`#4A4AFF`), with a slightly darker border.
*   **Correctly Placed Tile**: A different color to indicate a tile is in its correct final position, for example, a bright green (`#00FF00`).
*   **Empty Space**: A dark, inset look to clearly distinguish it from the tiles.
*   **Accent Color**: A vibrant color for highlighting the selected tile or for UI elements like buttons, such as a hot pink (`#FF00FF`).

## Typography

*   **Font**: A pixelated, monospace font to evoke a classic arcade game feel. A good candidate would be a font like "Press Start 2P" from Google Fonts or a similar open-source pixel font.
*   **Font Size**: Large, clear font sizes for the tile numbers and UI text.

## UI Elements

*   **Grid**: The puzzle grid should have a clear, chunky border.
*   **Tiles**: The tiles should be simple squares with a slight bevel or border to give them a sense of depth.
*   **Buttons**: Buttons (like "Shuffle") should be blocky and rectangular, with a simple, solid color fill and a pixelated border.
*   **Game Info**: The "Moves" and "Time" displays should use the same pixelated font and bright colors as the rest of the UI.
*   **Win Message**: A prominent message that appears upon winning, displaying the number of moves taken. It should be styled consistently with the retro theme.

## Animations and Transitions

*   **Tile Movement**: Tile movements should be quick and snappy, without any complex easing or smoothing. A simple, linear animation over a very short duration will give it a retro feel.
*   **Hover Effects**: A simple color change or a border highlight on hover for clickable tiles.

## Overall Feel

The goal is to create a visually engaging and nostalgic experience for the player. The design should be clean and readable, despite the retro aesthetic. The focus is on clear communication of the game state through a fun, retro lens.
